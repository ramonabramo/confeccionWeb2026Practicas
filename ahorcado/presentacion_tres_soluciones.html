Requisitos del Proyecto

Los 6 Hitos de Desarrollo del Ahorcado

Todo el alumnado debe construir el ejercicio de forma incremental validando cada etapa en pantalla:

Hito Nombre Comportamiento Esperado Validación en Aula
Hito 1 Palabra aleatoria & display Elegir palabra del banco y mostrar guiones bajos según su longitud. Palabra de 6 letras ➔ _ _ _ _ _ _
Hito 2 Lectura y validación de letra Comprobar que sea una letra válida (A-Z) y que no haya sido ya intentada. Intentar letra repetida ➔ Aviso visual
Hito 3 Destape de aciertos Sustituir guiones bajos por la letra en todas las posiciones coincidentes. Letra 'A' en 'PANTALLA' ➔ _ A _ _ A _ _ A
Hito 4 Dibujo progresivo del ahorcado Si la letra no está, restar una vida y mostrar la siguiente parte en el SVG. Fallo 1 ➔ Cabeza, Fallo 2 ➔ Tronco...
Hito 5 Condición de Victoria Si ya no quedan guiones bajos en pantalla, declarar victoria inmediata. Palabra completa ➔ 🎉 Mensaje ganador
Hito 6 Condición de Derrota Al llegar al máximo de fallos, mostrar cara de derrota y revelar la palabra. 6 fallos ➔ 💀 Game Over y solución

💡 El Secreto Pedagógico

En JavaScript, indexamos las partes en un array ordenado:

const partes = [cabeza, cuerpo, brazoIzq, ...];

// Al cometer el fallo N:
partes[fallos - 1].classList.add('visible');

Con solo 2 líneas de CSS (opacity: 0 y opacity: 1), el muñeco cobra vida paso a paso.

Opción 1 • Iniciación

Versión 1: Lógica Básica Lineal

La mejor opción para alumnos que están afianzando variables, bucles y condiciones:

Características Clave

  • Banco de palabras: Array simple de cadenas de texto.
  • Entrada: Campo <input type="text" maxlength="1">.
  • Búsqueda: Recorrido con bucle for (let i = 0; i < longitud; i++).
  • Display: Texto formateado con letrasAdivinadas.join(' ').
// Lógica de comprobación directa
if (palabraSecreta.includes(letra)) {
  for (let i = 0; i < palabraSecreta.length; i++) {
    if (palabraSecreta[i] === letra) {
      letrasAdivinadas[i] = letra;
    }
  }
} else {
  fallos++;
  partesAhorcado[fallos - 1].classList.add('visible');
}
Opción 2 • Intermedia

Versión 2: Teclado Virtual y Categorías

Avanza en la experiencia de usuario (UX) generando la botonera con JavaScript y capturando eventos eficientemente:

// 1. Delegación en el contenedor padre (Event Bubbling)
tecladoVirtual.addEventListener('click', e => {
  const btn = e.target.closest('.tecla');
  if (btn && !btn.disabled) jugarLetra(btn.dataset.letra);
});

// 2. Escuchador de teclado físico en tiempo real
window.addEventListener('keydown', e => {
  const l = e.key.toUpperCase();
  if (ALFABETO.includes(l)) jugarLetra(l);
});

Mejoras Introducidas

  • Objetos semánticos: { palabra, categoria, pista }.
  • Teclas con estado: .acierto (verde) y .fallo (rojo).
  • Casillas individuales: Cajas animadas en CSS para cada letra.
  • Marcador de corazones: Feedback emocional de vidas restantes.
Opción 3 • Profesional

Versión 3: Arquitectura POO, Audio y Persistencia

Desarrollo basado en clases y diseño de software modular para proyectos grandes:

Módulos Orientados a Objetos

  • SoundSynthesizer: Sintetizador Web Audio API puro (Do-Mi, arpegios, fanfarrias).
  • StatsRepository: Persistencia histórica en localStorage (rachas y % victorias).
  • AhorcadoEngine: Motor lógico matemático sin acoplamiento al DOM.
  • ConfettiAnimation: Partículas en <canvas> al ganar.
class AhorcadoEngine {
  probarLetra(letra) {
    // Lógica pura e inmutable
    const acierto = this.palabra.includes(letra);
    if (!acierto) this.fallos++;
    
    return {
      letra, acierto, fallos: this.fallos,
      victoria: !this.adivinadas.includes(''),
      derrota: this.fallos >= this.maxFallos
    };
  }
}
Comparativa Técnica

Evolución del Manejo de la Entrada del Usuario

Observa cómo la misma necesidad evoluciona a medida que madura la técnica de programación:

V1: Input de Texto

// Requiere teclear y pulsar botón
const l = input.value.toUpperCase();
input.value = '';
if (usadas.includes(l)) return;
usadas.push(l);

V2: Teclado Delegado

// Delegación en padre + Set
teclado.addEventListener('click', e => {
  const b = e.target.closest('.tecla');
  if (b && !usadas.has(b.dataset.l)) {
    usadas.add(b.dataset.l);
    b.disabled = true;
  }
});

V3: Desacoplamiento POO

// La vista delega en el motor
manejarJugada(letra) {
  const res = this.engine.probar(letra);
  if (!res) return;
  this.audio.playFeedback(res.acierto);
  this.ui.render(res);
}

Para el Docente

Cómo Evaluar y Calificar la Práctica

Rúbrica de Validación

  • Control de errores: Que una letra repetida o vacía no descuente vidas.
  • Destape exhaustivo: Si la letra aparece varias veces (ej. 'A' en 'PANTALLA'), deben desvelarse todas a la vez.
  • Sincronización gráfica: El número de fallos debe coincidir exactamente con las piezas visibles en el SVG.
  • Bloqueo final: Tras ganar o perder, no debe permitirse seguir jugando hasta reiniciar.

Estructura de Entrega al Alumno

  • Permite que consulten el archivo GUIA_PASO_A_PASO.md.
