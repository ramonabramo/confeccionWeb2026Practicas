🎮 Versión 2: Teclado Dinámico y UX Avanzada

Evolución profesional: sustituimos los inputs clásicos por un teclado interactivo en pantalla y objetos con metadatos.

🎯 Avances Técnicos

  • Inyección dinámica en el DOM con document.createElement.
  • Delegación de eventos sobre el contenedor padre (1 listener vs 27).
  • Integración nativa con teclado físico mediante window.addEventListener('keydown').
  • Uso de estructuras de datos Set para letras jugadas.

💎 Mejoras de Experiencia (UX)

  • Categorías & Pistas: Contexto temático y botón de ayuda.
  • Feedback por color: Verde si acierta, rojo tachado si falla.
  • Marcador con corazones: Indicador visual de vidas.
  • Casillas estilizadas: Cajas individuales para cada letra.

Hito 3: Generación del Teclado en el DOM

Generamos los 27 botones mediante código limpio y asociamos atributos de datos (dataset):

function renderizarTecladoVirtual() {
  tecladoVirtual.innerHTML = '';

  LETRAS_ALFABETO.forEach(letra => {
    const btn = document.createElement('button');
    btn.type = 'button';
    btn.className = 'tecla';
    btn.textContent = letra;
    btn.dataset.letra = letra; // Almacena el valor semántico
    
    tecladoVirtual.appendChild(btn);
  });
}

Hito 4: Delegación de Eventos y Teclado Físico

Aprovechamos el *Event Bubbling* para capturar clics en un solo punto y escuchamos teclas físicas:

// 1. Delegación en el contenedor padre (1 solo listener activo)
tecladoVirtual.addEventListener('click', evento => {
  const boton = evento.target.closest('.tecla');
  if (!boton || boton.disabled) return;
  jugarLetra(boton.dataset.letra);
});

// 2. Escuchador de teclado físico en window
window.addEventListener('keydown', evento => {
  if (juegoTerminado || evento.ctrlKey || evento.altKey) return;
  const letra = evento.key.toUpperCase();
  if (LETRAS_ALFABETO.includes(letra)) {
    jugarLetra(letra);
  }
});

Hito 5: La Función Unificada jugarLetra()

Un único punto de entrada procesa tanto los clics de ratón como las pulsaciones de teclado:

function jugarLetra(letra) {
  if (juegoTerminado || letrasUsadas.has(letra)) return;
  letrasUsadas.add(letra);

  const boton = tecladoVirtual.querySelector(`[data-letra="${letra}"]`);
  if (boton) boton.disabled = true;

  if (partidaActual.palabra.includes(letra)) {
    if (boton) boton.classList.add('acierto');
