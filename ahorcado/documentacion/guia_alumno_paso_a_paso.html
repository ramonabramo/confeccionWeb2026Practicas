Guía del alumno · JavaScript en el navegador

Vuestro ahorcado,
paso a paso

Buenas, soy Ramón Abramo, profesor con más de 25 años de experiencia docente. Esta guía os lleva de la mano para programar el juego del ahorcado de tres formas, de la más sencilla a la más profesional. Un paso por diapositiva, una prueba al final de cada paso y la solución escondida por si os atascáis.

Avanzad con → o con los botones de arriba.

Antes de empezar · Preparad el sitio de trabajo

Lo que necesitáis tener abierto

  1. Abrid la carpeta de la solución que vayáis a hacer (version-1-basica-lineal, version-2-teclado-eventos o version-3-avanzada-poo) en vuestro editor.
  2. El index.html carga un archivo llamado app.js. Si os he dado la plantilla como app.alumnos.js, renombradla a app.js antes de empezar. Ese es el archivo que vais a rellenar.
  3. Abrid el index.html en el navegador.
  4. Pulsad F12 y quedaos en la pestaña Consola[1]. Ahí veréis los errores en rojo y podréis probar cosas a mano.
no toquéis el index.html ni el main.css. Todo el trabajo va en app.js. Si cambiáis un id del HTML, vuestro JavaScript dejará de encontrarlo.

El ciclo de trabajo, siempre el mismo

✍️ Escribir→💾 Guardar Ctrl+S→🔄 Recargar F5→🧪 Probar

Parece una tontería, pero la mitad de los «no funciona» que veo en clase son archivos sin guardar o páginas sin recargar.

el ahorcado es como un examen tipo test con un único aspirante. Hay una respuesta secreta, el aspirante va marcando letras y alguien lleva la cuenta de los errores. Vuestro código es ese «alguien».

// → un entero del 0 al 7

¿Has ganado o has perdido?

después de cada jugada, comprobar si ya no quedan guiones (victoria) o si se han agotado las vidas (derrota). En los dos casos, bloquear la partida.

Pistas, en orden

  1. Victoria: !letrasAdivinadas.includes('_'). Poned juegoTerminado = true, un mensaje de 'exito' y llamad a finalizarPartida().
  2. Derrota (con else if): fallos >= MAX_FALLOS. Mostrad caraDerrota, enseñad la palabra entera y llamad también a finalizarPartida().

Ver la solución (solo si ya lo habéis intentado) 
function verificarFinJuego() {
  if (!letrasAdivinadas.includes('_')) {
    juegoTerminado = true;
    mostrarMensaje(`🎉 ¡Has ganado! La palabra es "${palabraSecreta}".`, 'exito');
    finalizarPartida();
  } else if (fallos >= MAX_FALLOS) {
    juegoTerminado = true;
    caraDerrota.classList.add('visible');
    palabraDisplay.textContent = palabraSecreta.split('').join(' ');
    mostrarMensaje(`💀 ¡Has perdido! La palabra era "${palabraSecreta}".`, 'error');
    finalizarPartida();
  }
}

Solución 3 · Paso 8 de 8 · Temporizador

45 segundos de reloj en el modo Difícil

en Difícil, mostrar la barra de tiempo, descontar un segundo cada segundo y dar la partida por perdida al llegar a cero. En Fácil y Normal, la barra no aparece.

dos retoques en AhorcadoEngine y un método nuevo en AhorcadoUI. La barra ya está en el HTML: caja-temporizador, tiempo-texto y barra-tiempo-fill.

Pistas, en orden

  1. Motor. Añadid tiempoMax: 45 a la configuración de dificil. Así el tiempo es una regla del juego, como las vidas.
  2. Motor. Un método tiempoAgotado() que ponga juegoTerminado = true y devuelva un informe igual que probarLetra(), con derrota: true y letra: null.
  3. Interfaz. Guardad en this.dom los tres elementos de la barra y modal-stat-tiempo. En el constructor, this.temporizador = null;.
  4. En iniciarTemporizador(): parad el reloj anterior con clearInterval[33]. Si la dificultad no tiene tiempoMax, ocultad la caja y return.
  5. Si lo tiene, con setInterval(..., 1000)[34] restad un segundo, repintad texto y barra y, al llegar a 0, this.finPartida(this.engine.tiempoAgotado()).
  6. Llamadlo al final de iniciar(), apuntando la hora de salida con Date.now()[35]. En finPartida(), lo primero, clearInterval(this.temporizador).
el reloj de ajedrez. Se pone en marcha al empezar, se para en cuanto termina la partida y, si llega a cero, pierdes aunque el tablero vaya bien.
elegid «Difícil»: aparece la barra con 45s y baja cada segundo. Dejad que llegue a cero sin jugar: teclado apagado, palabra destapada y la ventana dice «¡Tiempo agotado!». Ganad otra partida a tiempo: el reloj se queda quieto. Volved a «Normal»: la barra desaparece.
si el reloj corre al doble de velocidad después de cambiar de partida, os falta el clearInterval del principio: hay dos relojes funcionando a la vez. Si al ganar aparece después «¡Tiempo agotado!», falta pararlo en finPartida().
Ver la solución (solo si ya lo habéis intentado) 
// ---- AhorcadoEngine ----
dificil: { maxFallos: 5, pistasGratis: false, tiempoMax: 45 }

tiempoAgotado() {
  this.juegoTerminado = true;
  const max = this.configDificultades[this.dificultad].maxFallos;
  return { letra: null, acierto: false, fallos: this.fallos, maxFallos: max,
           victoria: false, derrota: true, palabraSecreta: this.itemActual.palabra };
}

// ---- AhorcadoUI ----
// En el constructor:
this.temporizador = null;
this.inicioPartida = 0;
// En this.dom:
cajaTiempo: document.getElementById('caja-temporizador'),
tiempoTexto: document.getElementById('tiempo-texto'),
barraTiempo: document.getElementById('barra-tiempo-fill'),
modalTiempo: document.getElementById('modal-stat-tiempo'),

// Al final de iniciar():
this.inicioPartida = Date.now();
this.iniciarTemporizador();

iniciarTemporizador() {
  clearInterval(this.temporizador);
  const max = this.engine.configDificultades[this.engine.dificultad].tiempoMax;

  if (!max) {
    this.dom.cajaTiempo.classList.add('oculta');
    return;
  }

  let restantes = max;
  const pintar = () => {
    this.dom.tiempoTexto.textContent = `${restantes}s`;
    this.dom.barraTiempo.style.width = `${(restantes / max) * 100}%`;
  };

  this.dom.cajaTiempo.classList.remove('oculta');
  pintar();

  this.temporizador = setInterval(() => {
    restantes--;
    pintar();
    if (restantes <= 0) {
      clearInterval(this.temporizador);
      this.finPartida(this.engine.tiempoAgotado());
    }
  }, 1000);
}

// En finPartida(res): primera línea
clearInterval(this.temporizador);
// ... y en la rama de derrota:
this.dom.modalTitulo.textContent = res.letra === null ? '¡Tiempo agotado!' : 'Derrota';
// ... y junto a la racha y las vidas:
this.dom.modalTiempo.textContent = `${Math.round((Date.now() - this.inicioPartida) / 1000)}s`;
