Módulo de Audio: Web Audio API Puro

Generación de ondas sinusoidales armónicas en tiempo real sin requerir archivos de audio:

class SoundSynthesizer {
  playTone(frequency, type, duration) {
    if (this.muted) return;
    const osc = this.audioCtx.createOscillator();
    const gain = this.audioCtx.createGain();

    osc.type = type; // 'sine' | 'triangle' | 'sawtooth'
    osc.frequency.setValueAtTime(frequency, this.audioCtx.currentTime);
    gain.gain.exponentialRampToValueAtTime(0.001, this.audioCtx.currentTime + duration);

    osc.connect(gain);
    gain.connect(this.audioCtx.destination);
    osc.start();
    osc.stop(this.audioCtx.currentTime + duration);
  }
}

Módulo de Persistencia: StatsRepository

Encapsulamos la comunicación con localStorage serializando con JSON:

class StatsRepository {
  recordGame(victory) {
    this.stats.partidas++;
    if (victory) {
      this.stats.victorias++;
      this.stats.rachaActual++;
      if (this.stats.rachaActual > this.stats.mejorRacha) {
        this.stats.mejorRacha = this.stats.rachaActual;
      }
    } else {
      this.stats.derrotas++;
      this.stats.rachaActual = 0;
    }
    localStorage.setItem('ahorcado_stats', JSON.stringify(this.stats));
  }
}

Niveles de Dificultad Dinámicos

Configuraciones adaptativas que modifican la experiencia de juego:

🟢 Fácil

  • 8 vidas (incluye manos del ahorcado).
  • Revela automáticamente 2 letras iniciales.
  • Pistas ilimitadas y sin presión de tiempo.

🔴 Difícil (Contrarreloj)

  • 5 vidas máximas.
  • Sin pistas temáticas.
  • Temporizador regresivo de 45s con barra animada.
