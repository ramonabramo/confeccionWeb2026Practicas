🎮 Versión 1: Lógica Básica Lineal

Construyendo el juego del ahorcado desde cero con conceptos elementales de programación imperativa.

🎯 Objetivos de Aprendizaje

  • Manipulación directa del DOM con getElementById.
  • Gestión de estado en memoria mediante variables y arrays.
  • Lectura y validación de datos desde un <input>.
  • Uso de bucles for tradicionales para recorrer cadenas.

🧱 Componentes Principales

  • Display: Muestra la palabra con guiones _ _ _ _.
  • Ahorcado SVG: Piezas que se destapan con cada error.
  • Entrada: Caja de texto para probar una letra a la vez.
  • Marcador: Control de vidas restantes (6 a 0).

Hito 1 y 2: Memoria del Juego y Selectores DOM

Definimos el banco de palabras y las variables globales que registran qué está ocurriendo en la partida:

const PALABRAS = ['JAVASCRIPT', 'VARIABLE', 'FUNCION', 'OBJETO'];
const MAX_FALLOS = 6;

let palabraSecreta = '';    // Ej: "VARIABLE"
let letrasAdivinadas = [];  // Ej: ['V', '_', 'R', '_', ...]
let letrasUsadas = [];      // Ej: ['A', 'E', 'X']
let fallos = 0;             // 0 a 6

// Referencias a los 6 elementos del ahorcado en el SVG
const partesAhorcado = [
  document.getElementById('parte-cabeza'),
  document.getElementById('parte-cuerpo'),
  document.getElementById('parte-brazo-izq'),
  document.getElementById('parte-brazo-der'),
  document.getElementById('parte-pierna-izq'),
  document.getElementById('parte-pierna-der')
];

Hito 3: Función iniciarJuego()

Seleccionamos una palabra al azar y preparamos el array de guiones bajos:

function iniciarJuego() {
  // 1. Elegir palabra aleatoria
  const indice = Math.floor(Math.random() * PALABRAS.length);
  palabraSecreta = PALABRAS[indice];

  // 2. Llenar letrasAdivinadas con tantos '_' como longitud tenga la palabra
  letrasAdivinadas = [];
  for (let i = 0; i < palabraSecreta.length; i++) {
    letrasAdivinadas.push('_');
  }

  // 3. Resetear contadores y ocultar piezas del ahorcado
  fallos = 0;
  letrasUsadas = [];
  partesAhorcado.forEach(parte => parte.classList.remove('visible'));

  actualizarPantalla();
}

Hito 4: Procesar y Comprobar la Letra

Validamos la letra y comprobamos si está dentro de la palabra secreta:

function procesarLetra() {
  const letra = inputLetra.value.trim().toUpperCase();
  if (!letra || letrasUsadas.includes(letra)) return;

  letrasUsadas.push(letra);

  if (palabraSecreta.includes(letra)) {
    // ACIERTO: Recorremos y revelamos
    for (let i = 0; i < palabraSecreta.length; i++) {
      if (palabraSecreta[i] === letra) {
        letrasAdivinadas[i] = letra;
      }
    }
  } else {
    // FALLO: Mostramos la siguiente pieza del ahorcado
    fallos++;
    partesAhorcado[fallos - 1].classList.add('visible');
  }

  actualizarPantalla();
  verificarFinJuego();
}

Hito 5 y 6: Actualización y Fin de Partida

Comprobamos si el alumno ha ganado (sin guiones) o ha agotado sus vidas (6 fallos):

function verificarFinJuego() {
  // VICTORIA: ¡Ya no queda ningún guion bajo en el array!
  if (!letrasAdivinadas.includes('_')) {
    juegoTerminado = true;
    mostrarMensaje('🎉 ¡Has ganado!', 'exito');
    finalizarPartida();
    return;
  }

  // DERROTA: Se han cometido 6 fallos
  if (fallos >= MAX_FALLOS) {
    juegoTerminado = true;
    palabraDisplay.textContent = palabraSecreta.split('').join(' ');
    mostrarMensaje('💀 ¡Game Over!', 'error');
    finalizarPartida();
  }
}
