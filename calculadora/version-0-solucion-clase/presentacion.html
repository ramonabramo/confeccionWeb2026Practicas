La Solución de Clase de Ramón Abramo

Esta versión es la explicada directamente en la pizarra: función pura calcular(), tres colecciones en el DOM (numeros, operadores, acciones) y manipulación directa sobre la pantalla.

1. Función Pura

calcular(n1, n2, op) no depende de variables externas; recibe valores y devuelve el resultado.

2. 3 Grupos Semánticos

Agrupamos botones en numeros, operadores y acciones ('igual' y 'borrar').

3. Estado Eficiente

empezarNumero, operadorPendiente, numeroAnterior y numeroActual.

Paso 1

1. La Función Pura de Cálculo

Recibe dos números y el operador. Controla la división por cero devolviendo 'Error'.

function calcular(numero1, numero2, operacion) {
    let resultado = 0;

    switch (operacion) {
        case '+':
            resultado = numero1 + numero2;
            break;
        case '-':
            resultado = numero1 - numero2;
            break;
        case '*':
            resultado = numero1 * numero2;
            break;
        case '/':
            if (numero2 === 0) {
                resultado = 'Error';
            } else {
                resultado = numero1 / numero2;
            }
            break;
    }

    return resultado;
}
💡 ¿Por qué es una función pura?

Porque no modifica variables globales. Para los mismos parámetros de entrada, siempre devuelve exactamente el mismo resultado. Esto la hace 100% testeable y libre de efectos secundarios.

Paso 2

2. Memoria de Estado y Selección en el DOM

Las variables que recuerdan la operación y los 3 selectores de botones.

Memoria de Estado
// Limpiar display tras operador

// Operación pendiente (+, -, *, /)
let operadorPendiente = null;

// Número antes de pulsar operador
let numeroAnterior = null;

// Número actual en pantalla
let numeroActual = null;
Selectores del DOM
const numeros =

const acciones =

Paso 3

3. Pulsación de Números (0 al 9)

Sustituye el '0' inicial o limpia la pantalla si venimos de pulsar un operador.

La regla de la pantalla
  • Si pantalla.textContent === '0' o empezarNumero === true: escribimos el nuevo valor limpio y apagamos la bandera.
  • En caso contrario: concatenamos con += detrás de los existentes.
🧪 Prueba: Teclea 7 8 9 ➔ Muestra 789. 
numeros.forEach(numero => {
    numero.addEventListener('click', () => {
        const valor = numero.dataset.numero;

        if (pantalla.textContent === '0' || empezarNumero) {
            pantalla.textContent = valor;
            empezarNumero = false;
        } else {
            pantalla.textContent += valor;
        }
    });
});
Paso 4

4. Pulsación de Operadores (+, -, *, /)

Memoriza la operación y resuelve subtotales si el usuario encadena cálculos.

operadores.forEach(operador => {
    operador.addEventListener('click', () => {
        const valor = operador.dataset.operador;

        // Si ya había operador pendiente, resolvemos subtotal
        if (operadorPendiente !== null && empezarNumero !== true) {
            numeroActual = Number(pantalla.textContent);
            numeroAnterior = calcular(numeroAnterior, numeroActual, operadorPendiente);
            pantalla.textContent = numeroAnterior;
        } else {
            numeroAnterior = Number(pantalla.textContent);
        }

        // Control de Error y bandera de pantalla limpia
        operadorPendiente = (numeroAnterior === 'Error') ? null : valor;
        empezarNumero = true;
    });
});
Puntos Clave
  • Usa Number(pantalla.textContent) para convertir a número.
  • Si numeroAnterior === 'Error', desactiva operadorPendiente para no arrastrar el fallo.
  • empezarNumero = true garantiza que el siguiente número no se pegue.
Paso 5

5. Acciones: Botón Igual (=) y Borrar (C)

Un solo bucle para el grupo acciones mediante una estructura switch.

Dos casos claros
  • case 'igual': Si hay operador pendiente, llama a calcular() y muestra el total. Resetea operadorPendiente = null.
  • case 'borrar': Pone la pantalla en '0' y resetea las variables.
🧪 Prueba Igual: 7 + 8 = ➔ 15
🧪 Prueba Borrar: 999 C ➔ 0 
acciones.forEach(accion => {
    accion.addEventListener('click', () => {
        const valor = accion.dataset.accion;

        switch (valor) {
            case 'igual':
                if (operadorPendiente !== null) {
                    numeroActual = Number(pantalla.textContent);
                    numeroAnterior = calcular(numeroAnterior, numeroActual, operadorPendiente);
                    pantalla.textContent = numeroAnterior;
                }
                operadorPendiente = null;
                empezarNumero = true;
                break;

            case 'borrar':
                pantalla.textContent = '0';
                operadorPendiente = null;
                empezarNumero = true;
                break;
        }
    });
});
