Calculadora por Hitos de Funcionamiento

Aprenderemos a programar la calculadora paso a paso, viendo resultados funcionales en cada etapa: primero los números, luego la suma, luego el resultado, y así hasta completarla.

1. Ver resultados ya

Cada hito termina con una prueba visual en el navegador. No escribimos código a ciegas.

2. Escuchadores Directos

Usamos forEach para asignar un addEventListener a cada botón individualmente.

3. Modularidad

Construimos funciones pequeñas que se encargan de una sola tarea a la vez.

La Hoja de Ruta

Los 7 Hitos de Funcionamiento

¿Qué sabrá hacer nuestra calculadora en cada etapa?

  • HITO 1 Pintar números: Al pulsar 1, 2, 3... se ven en la pantalla LCD.
  • HITO 2 Aprender a sumar (+): Guardar el primer número y preparar la pantalla.
  • HITO 3 Resolver con (=): Calcular la suma y mostrar el total.
  • HITO 4 Más operaciones: Resta (-), Multiplicación (*) y División (/).
  • HITO 5 Operaciones encadenadas: Recordar acumulado (ej: 5 + 3 + 2 = 10).
  • HITO 6 Botón Borrar (C): Devolver toda la memoria a cero.
  • HITO 7 Casos límite: Manejar división por cero (Error) y redondeo decimal.
Hito 1

[HITO 1] Escribir Números en Pantalla

Objetivo: Que al hacer clic en cualquier tecla del 0 al 9, el número aparezca en el display.

Lógica a implementar
  • Si reiniciarDisplay es true, el nuevo número limpia la pantalla.
  • Si la pantalla tiene '0', lo reemplazamos (para no mostrar "07").
  • En cualquier otro caso, concatenamos: '1' + '2' = '12'.
🧪 Prueba del alumno: Pulsa 1, 2, 3 en la calculadora ➔ Debe verse 123. 
function agregarNumero(numero) {
    if (reiniciarDisplay) {
        operandoActual = numero;
        reiniciarDisplay = false;
    } else {
        operandoActual = (operandoActual === '0') 
            ? numero 
            : operandoActual + numero;
    }
    actualizarDisplay();
}

// Escuchador a cada botón de número
botonesNumeros.forEach((boton) => {
    boton.addEventListener('click', () => {
        agregarNumero(boton.dataset.numero);
    });
});
Hito 2

[HITO 2] Guardar Memoria y Elegir Suma (+)

Objetivo: Al pulsar '+', la calculadora guarda el primer número y prepara la pantalla.

¿Qué hace la memoria?
  • Guarda operandoActual en operandoAnterior.
  • Guarda el operador seleccionado en operacion.
  • Activa reiniciarDisplay = true para que el siguiente número empiece limpio y no se pegue al anterior.
🧪 Prueba del alumno: Escribe 15, pulsa +, escribe 4 ➔ En pantalla se ve 4 (el 15 está en memoria). 
function seleccionarOperador(nuevoOperador) {
    // Si ya había una operación pendiente, calcula primero
    if (operacion !== null && !reiniciarDisplay) {
        calcular();
    }

    operandoAnterior = operandoActual;
    operacion = nuevoOperador;
    reiniciarDisplay = true;
}

// Escuchador a cada operador
botonesOperadores.forEach((boton) => {
    boton.addEventListener('click', () => {
        seleccionarOperador(boton.dataset.operador);
    });
});
Hito 3

[HITO 3] Resolver con el Botón Igual (=)

Objetivo: Al pulsar '=', convertir texto a número con parseFloat() y realizar la suma.

function calcular() {
    if (operacion === null || operandoAnterior === null) return;

    const anterior = parseFloat(operandoAnterior);
    const actual = parseFloat(operandoActual);
    let resultado;

    switch (operacion) {
        case '+':
            resultado = anterior + actual;
            break;
    }

    operandoActual = resultado.toString();
    operacion = null;
    operandoAnterior = null;
    reiniciarDisplay = true;
    actualizarDisplay();
}

// Escuchador para la tecla =
botonIgual.addEventListener('click', () => calcular());
¡La primera suma funciona!

Convertimos las cadenas de texto con parseFloat() porque si hiciéramos "7" + "8" en JavaScript resultaría en "78".

🧪 Prueba del alumno: Teclea 7 + 8 = ➔ La pantalla muestra 15.
Hito 4

[HITO 4] Añadir Resta (-), Multiplicación (*) y División (/)

Objetivo: Ampliar el switch de la función calcular() para cubrir las 4 operaciones básicas.

switch (operacion) {
    case '+': 
        resultado = anterior + actual; 
        break;
    case '-': 
        resultado = anterior - actual; 
        break;
    case '*': 
        resultado = anterior * actual; 
        break;
    case '/':
        resultado = (actual === 0) 
            ? 'Error' 
            : anterior / actual;
        break;
}
Batería de Pruebas
🧪 Resta: 9 - 4 = ➔ 5

🧪 Multiplicación: 6 * 3 = ➔ 18

🧪 División: 20 / 4 = ➔ 5
Hito 5

[HITO 5] Operaciones Encadenadas

Objetivo: Que al escribir 5 + 3 + 2 =, al pulsar el segundo + ya calcule automáticamente 8.

¿Cómo lo detectamos?
  • Al pulsar cualquier operador, comprobamos si operacion !== null.
  • Si es así, invocamos a calcular() antes de asignar la nueva operación.
  • El usuario no necesita pulsar el botón = entre medias.
🧪 Prueba del alumno: Teclea 5 + 3 + ➔ En el segundo + la pantalla se actualiza sola a 8. Luego teclea 2 = ➔ Muestra 10. 
function seleccionarOperador(nuevoOperador) {
    // Si ya había una operación y se introdujo un número:
    if (operacion !== null && !reiniciarDisplay) {
        calcular(); // Resuelve 5 + 3 = 8
    }

    operandoAnterior = operandoActual; // Memoriza 8
    operacion = nuevoOperador;         // Memoriza el nuevo +
    reiniciarDisplay = true;
}
Hito 6

[HITO 6] Botón de Borrado (Tecla 'C')

Objetivo: Devolver la calculadora y sus variables a los valores iniciales de fábrica.

Reset Completo
  • operandoActual = '0'
  • operandoAnterior = null
  • operacion = null
  • reiniciarDisplay = false
🧪 Prueba del alumno: Escribe 999, pulsa C ➔ La pantalla vuelve limpiamente a 0. 
function borrar() {
    operandoActual = '0';
    operandoAnterior = null;
    operacion = null;
    reiniciarDisplay = false;
    actualizarDisplay();
}

// Escuchador para la tecla C
botonBorrar.addEventListener('click', () => borrar());
Hito 7

[HITO 7] Casos Límite y Afinamiento

Objetivo: Blindar la calculadora ante errores matemáticos e imprecisiones de JavaScript.

1. División por Cero

Evitamos que aparezca Infinity protegiendo la división:

if (actual === 0) {
    resultado = 'Error';
} else {
    resultado = anterior / actual;
}
🧪 Prueba: 8 / 0 = ➔ Error
2. Redondeo Decimal

En JS, 0.1 + 0.2 = 0.30000000000000004. Lo arreglamos redondeando:

if (typeof resultado === 'number') {
    resultado = Math.round(resultado * 100000000) / 100000000;
}
