Buenas, soy Ramón Abramo, profesor con más de 25 años de experiencia docente. Esta guía os lleva de la mano para programar la calculadora de tres formas distintas. Un paso por diapositiva, una prueba al final de cada paso y la solución escondida por si os atascáis.

Antes de empezar · Preparad el sitio de trabajo

Lo que necesitáis tener abierto

  1. Abrid la carpeta de la solución que vais a hacer en vuestro editor (Visual Studio Code, por ejemplo).
  2. Dentro tenéis index.html, main.css y app.js. Solo vais a tocar app.js, que es la plantilla con los comentarios TODO.

El ciclo que vais a repetir mil veces

✍️ Escribir→💾 Guardar→🔄 Recargar (F5)→🧪 Probar

Parece una tontería, pero la mitad de las dudas que me llegan son de alguien que no ha guardado o no ha recargado. Si cambiáis el código y la página sigue igual, sospechad primero de eso.

Y una regla de oro: no paséis al siguiente paso hasta que la prueba del actual salga bien. Si acumuláis cinco pasos sin probar y algo falla, no sabréis cuál de los cinco ha sido.

Hay tres tipos de botones, y se distinguen por su atributo data-:

  • data-numero → del 0 al 9 (10 botones).
  • data-operador → + - * / (4 botones).
  • data-accion → igual y borrar (2 botones).
son como las etiquetas de los botes de la cocina: todos los botes son iguales, pero la etiqueta os dice qué hay dentro.

Desde JavaScript, data-numero="7" se lee como boton.dataset.numero y vale '7', con comillas: es texto[2].

Antes de empezar · La memoria de la calculadora

Cuatro cosas que la calculadora tiene que recordar

Pensad en lo que pasa cuando tecleáis 15 + 4 =. Para poder decir 19, la calculadora necesita tener apuntado:

  1. Lo que hay ahora en pantalla → 4
  2. El número de antes → 15
  3. La operación pendiente → +
  4. Una bandera que diga: «el próximo dígito empieza un número nuevo, no lo pegues al de antes».
un camarero con su libreta. Apunta el primer plato, qué queréis hacer con él y luego el segundo. Si no apunta, se le olvida.

La función calcular()

una función que recibe dos números y una operación, y devuelve el resultado. No toca la pantalla ni ninguna variable de fuera.

bloque TODO 0.1, dentro de function calcular(numero1, numero2, operacion).

Pistas, en orden

  1. Escribid un switch (operacion)[8].
  2. Un case para cada operador: '+', '-', '*' y '/'. En cada uno, guardad la cuenta en resultado.
  3. Terminad cada case con break.
  4. En la división: si numero2 === 0, resultado = 'Error'; si no, dividid[9].
  5. El return resultado; ya está escrito al final. No lo toquéis.
una exprimidora. Le dais dos naranjas y le decís «zumo». Os da zumo. No le importa de dónde vienen las naranjas.
esta función se puede probar sin tocar ni un botón. Recargad y escribid en la consola:
calcular(7, 8, '+') → 15
calcular(9, 4, '-') → 5
calcular(8, 0, '/') → 'Error'
calcular(9, 4, '+') da 5 en vez de 13: os falta un break y el código se «cae» al caso de abajo. Si da 0, revisad que escribís '+' con comillas en el case.
Ver la solución (solo si ya lo habéis intentado) 
function calcular(numero1, numero2, operacion) {
    let resultado = 0;

    switch (operacion) {
        case '+':
            resultado = numero1 + numero2;
            break;
        case '-':
            resultado = numero1 - numero2;
            break;
        case '*':
            resultado = numero1 * numero2;
            break;
        case '/':
            if (numero2 === 0) {
                resultado = 'Error';
            } else {
                resultado = numero1 / numero2;
            }
            break;
    }

    return resultado;
}

Errores y decimales

dividir entre cero muestra Error, después de un error no se sigue operando, y los decimales no salen con quince cifras.

Parte A · No seguir operando tras un error

bloque TODO 2 (operadores), la línea de operadorPendiente = valor.

Cambiadla por un ternario[12]: si numeroAnterior es 'Error', el operador pendiente vuelve a null; si no, se guarda valor.

Parte B · Redondear (no viene en la plantilla)

dentro de calcular(), justo antes del return.

Si el resultado es un número (typeof resultado === 'number'[13]), redondeadlo a 8 decimales: multiplicad por 100000000, redondead con Math.round[14] y volved a dividir.

8 / 0 = → Error.
8 / 0 + → Error, y el + no queda pendiente.
10 / 3 = → 3.33333333 (antes salía 3.3333333333333335).
Ver la solución (solo si ya lo habéis intentado) 
// Parte A: en los operadores
operadorPendiente = (numeroAnterior === 'Error') ? null : valor;

// Parte B: en calcular(), antes del return
if (typeof resultado === 'number') {
    resultado = Math.round(resultado * 100000000) / 100000000;
}
return resultado;
el typeof está para no intentar redondear el texto 'Error'. Sin él, Math.round devolvería NaN.

function calcular() {
    if (operacion === null || operandoAnterior === null) return;

    const anterior = parseFloat(operandoAnterior);
    const actual = parseFloat(operandoActual);
    let resultado;

    switch (operacion) {
        case '+':
            resultado = anterior + actual;
            break;
        default:
            return;
    }

    operandoActual = resultado.toString();
    operacion = null;
    operandoAnterior = null;
    reiniciarDisplay = true;
    actualizarDisplay();
}

botonIgual.addEventListener('click', () => {
    calcular();
});

Solución 2 · La idea antes del código

El clic sube como una burbuja

Cuando hacéis clic en un botón, el aviso no se queda en el botón: sube a su padre (.teclado), luego al padre de ese, y así hasta arriba. Se llama burbujeo[18].

Si ponemos un escuchador en .teclado, se enterará de los clics de todos sus botones.

el conserje de un edificio. Todos los paquetes llegan a la portería; el conserje mira la etiqueta y los sube al piso que toca. No hace falta un vigilante en cada puerta.

Dos cosas que el conserje tiene que averiguar

  1. ¿Qué botón han pulsado? evento.target es el elemento exacto donde cayó el clic[19]. .closest('button') sube desde ahí hasta encontrar el botón[20]. Si el clic cayó en un hueco entre teclas, devuelve null.
  2. ¿Qué etiqueta lleva? Lo leemos de boton.dataset. Las etiquetas que no tiene valen undefined.

function calcular() {
    if (operacion === null || operandoAnterior === null) return;

    const anterior = parseFloat(operandoAnterior);
    const actual = parseFloat(operandoActual);
    let resultado;

    switch (operacion) {
        case '+':
            resultado = anterior + actual;
            break;
        default:
            return;
    }

    operandoActual = resultado.toString();
    operacion = null;
    operandoAnterior = null;
    reiniciarDisplay = true;
    actualizarDisplay();
}
