Desarrollo Incremental con Delegación

Calculadora por Hitos de Funcionamiento

Desarrollamos cada función paso a paso mientras canalizamos todos los eventos a través de un único escuchador en el contenedor .teclado gracias al borboteo de eventos.

1. Probar cada hito

Cada paso resuelve una necesidad real del usuario: escribir números, sumar, ver total, etc.

2. Delegación Óptima

1 solo addEventListener con closest('button') y lectura directa de dataset.

3. Escalable

Cualquier botón nuevo en el HTML funciona automáticamente sin registrar nuevos escuchadores.

La Hoja de Ruta

Los 7 Hitos de Funcionamiento

Progresión paso a paso de la calculadora:

  • HITO 1 Pintar números: Teclear dígitos y verlos en el display LCD.
  • HITO 2 Aprender a sumar (+): Guardar memoria y preparar pantalla.
  • HITO 3 Resolver con (=): Calcular la suma y ver resultado.
  • HITO 4 Más operaciones: Resta (-), Multiplicación (*) y División (/).
  • HITO 5 Operaciones encadenadas: Recordar acumulado (ej: 5 + 3 + 2 = 10).
  • HITO 6 Botón Borrar (C): Devolver toda la memoria a cero.
  • HITO 7 Casos límite: Manejar división por cero (Error) y decimales.
Hito 1

[HITO 1] Escribir Números en Pantalla

Objetivo: Al pulsar teclas del 0 al 9, mostrarlas en el display.

Lógica
  • Si reiniciarDisplay es true, el nuevo número limpia la pantalla.
  • Si la pantalla tiene '0', se sustituye por el nuevo número.
  • En caso contrario, se concatena al final.
🧪 Prueba del alumno: Pulsa 1, 2, 3 en la calculadora ➔ Debe verse 123. 
function agregarNumero(numero) {
    if (reiniciarDisplay) {
        operandoActual = numero;
        reiniciarDisplay = false;
    } else {
        operandoActual = (operandoActual === '0') 
            ? numero 
            : operandoActual + numero;
    }
    actualizarDisplay();
}
Hito 2

[HITO 2] Guardar Memoria y Elegir Suma (+)

Objetivo: Al pulsar '+', recordar el primer número y dejar lista la pantalla para el segundo.

El Estado en Memoria
  • operandoAnterior = operandoActual (guarda el 1er número).
  • operacion = nuevoOperador (guarda el '+').
  • reiniciarDisplay = true (indica que el siguiente dígito reemplazará la pantalla).
🧪 Prueba del alumno: Escribe 15, pulsa +, escribe 4 ➔ En pantalla se ve 4 (el 15 está a salvo en memoria). 
function seleccionarOperador(nuevoOperador) {
    // Si ya había una operación previa, calcula antes (Hito 5)
    if (operacion !== null && !reiniciarDisplay) {
        calcular();
    }

    operandoAnterior = operandoActual;
    operacion = nuevoOperador;
    reiniciarDisplay = true;
}
Hito 3

[HITO 3] Resolver con el Botón Igual (=)

Objetivo: Al pulsar '=', convertir texto a número con parseFloat() y calcular la suma.

function calcular() {
    if (operacion === null || operandoAnterior === null) return;

    const anterior = parseFloat(operandoAnterior);
    const actual = parseFloat(operandoActual);
    let resultado;

    switch (operacion) {
        case '+':
            resultado = anterior + actual;
            break;
    }

    operandoActual = resultado.toString();
    operacion = null;
    operandoAnterior = null;
    reiniciarDisplay = true;
    actualizarDisplay();
}
¡El primer cálculo funciona!

Usamos parseFloat() para que "7" + "8" no se concatene como texto, sino que se sume aritméticamente como 15.

🧪 Prueba del alumno: Teclea 7 + 8 = ➔ La pantalla muestra 15.
Hito 4

[HITO 4] Añadir Resta (-), Multiplicación (*) y División (/)

Objetivo: Completar el switch de la función calcular() para todas las operaciones.

switch (operacion) {
    case '+': 
        resultado = anterior + actual; 
        break;
    case '-': 
        resultado = anterior - actual; 
        break;
    case '*': 
        resultado = anterior * actual; 
        break;
    case '/':
        resultado = (actual === 0) 
            ? 'Error' 
            : anterior / actual;
        break;
}
Batería de Pruebas
🧪 Resta: 9 - 4 = ➔ 5

🧪 Multiplicación: 6 * 3 = ➔ 18

🧪 División: 20 / 4 = ➔ 5
Hito 5

[HITO 5] Operaciones Encadenadas

Objetivo: Que al teclear 5 + 3 + 2 =, al pulsar el segundo + calcule primero 8.

Manejo Automático

Dentro de seleccionarOperador() detectamos si ya existía una operación pendiente y llamamos a calcular().

🧪 Prueba del alumno: Teclea 5 + 3 + ➔ En el segundo + la pantalla se actualiza sola a 8. Luego teclea 2 = ➔ Muestra 10. 
function seleccionarOperador(nuevoOperador) {
    if (operacion !== null && !reiniciarDisplay) {
        calcular(); // Resuelve el subtotal
    }

    operandoAnterior = operandoActual;
    operacion = nuevoOperador;
    reiniciarDisplay = true;
}
Hito 6 & Eventos

[HITO 6] Borrado (C) y Delegación en el Teclado

Un único escuchador centraliza todos los hitos anteriores:

teclado.addEventListener('click', (evento) => {
    const boton = evento.target.closest('button');
    if (!boton) return;

    const { numero, operador, accion } = boton.dataset;

    if (numero !== undefined) {
        agregarNumero(numero);          // HITO 1
    } else if (operador !== undefined) {
        seleccionarOperador(operador);  // HITO 2, 4, 5
    } else if (accion === 'igual') {
        calcular();                     // HITO 3
    } else if (accion === 'borrar') {
        borrar();                       // HITO 6
    }
});
Función Borrar (C)
function borrar() {
    operandoActual = '0';
    operandoAnterior = null;
    operacion = null;
    reiniciarDisplay = false;
    actualizarDisplay();
}
🧪 Prueba: Teclea 999, pulsa C ➔ Vuelve a 0.
Hito 7

[HITO 7] Control de Errores y Afinamiento

Protegemos la aplicación ante divisiones entre cero e imprecisiones de punto flotante.

1. División entre Cero
if (actual === 0) {
    resultado = 'Error';
} else {
    resultado = anterior / actual;
}
🧪 Prueba: 8 / 0 = ➔ Error
2. Redondeo Flotante

Evita que 0.1 + 0.2 muestre 0.30000000000000004:

if (typeof resultado === 'number') {
    resultado = Math.round(resultado * 100000000) / 100000000;
}
